# React Movie Project

A movie browsing app built with React and Vite.

## Features

- Browse a list of movies
- View movie details and cards
- Save favorites locally in the app
- Responsive React UI

## Getting started

1. Install dependencies:
   npm install
2. Start the development server:
   npm run dev
3. Build for production:
   npm run build

## Tech stack

- React
- Vite
- CSS modules / custom styling
